# SistemaVenta

Sistema de facturación e inventario desarrollado en Java para la administración de pequeños y medianos negocios.

## Descripción

Sistema de escritorio orientado a la gestión de ventas, inventario y administración comercial.  
Permite controlar productos, clientes, proveedores y procesos de facturación de manera eficiente.

Este proyecto fue desarrollado utilizando Java Swing y MySQL.

---

# Características principales

- Inicio de sesión de usuarios
- Gestión de productos
- Control de inventario
- Registro de ventas
- Administración de clientes
- Gestión de proveedores
- Reportes
- Control de stock mínimo
- Roles de usuario
- Interfaz gráfica en Java Swing

---

# Tecnologías utilizadas

- Java
- Java Swing
- MySQL
- JDBC
- JasperReports
- NetBeans
